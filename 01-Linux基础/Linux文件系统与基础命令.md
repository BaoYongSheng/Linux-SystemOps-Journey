\# Linux 文件系统与基础命令



\## 一、文件系统结构

\- / 根目录

\- \~ 家目录（/home/naqin）

\- 绝对路径 vs 相对路径



\## 二、常用命令（命令 + 作用 + 例子）

\- pwd：看当前在哪

\- ls / ls -l / ls -a

\- cd

\- mkdir

\- touch

\- cp / cp -r

\- mv

\- rm / rm -r / rm -rf（危险！）



\## 三、隐藏文件

\- 以 . 开头，ls -a 才能看到



\## 四、权限基础

\- ls -l 第一列如 -rw-rw-r--

\- r 读 / w 写 / x 执行

\- 属主 / 属组 / 其他



\## 五、今天踩的坑（排错记录）

\- mv 不需要 -r

\- home 目录写 \~ 或 ../，不是 home/

\- cp 时看清源文件

\- rm 后别再复制回来
